# Code of Conduct

## Our commitment

We want Mantis to be a welcoming, useful project for operators, developers, contributors, and users with different backgrounds and levels of experience.

We commit to making participation in this project free from harassment and discrimination. We expect everyone participating in project spaces to act with respect, good faith, and professionalism.

## Expected behavior

Examples of behavior that contributes to a healthy community include:

- Being respectful of differing viewpoints and experience levels.
- Giving and accepting constructive technical feedback.
- Focusing criticism on ideas, code, and outcomes rather than people.
- Being clear about uncertainty, mistakes, and tradeoffs.
- Respecting privacy and avoiding disclosure of credentials, private infrastructure details, or other sensitive information.
- Helping keep discussions relevant and productive.

## Unacceptable behavior

Unacceptable behavior includes:

- Harassment, threats, intimidation, or discriminatory language.
- Personal attacks, insults, or sustained hostile behavior.
- Sexualized language or attention in project spaces.
- Publishing another person's private information without permission.
- Deliberately disrupting issues, pull requests, reviews, or discussions.
- Abusing project access, infrastructure details, credentials, or security information.
- Other conduct that a reasonable person would consider inappropriate in a professional open-source project.

## Scope

This Code of Conduct applies in repository issues, pull requests, reviews, discussions, and other project-managed spaces. It also applies when someone is representing the project in a public project-related context.

## Reporting and enforcement

If a concern is safe to discuss publicly, you may raise it in the relevant issue or pull request and ask a maintainer to step in.

For concerns that should remain private, contact the project maintainer using a private contact method listed on the maintainer's GitHub profile. Do not post sensitive personal information publicly just to report conduct.

Project maintainers may remove, edit, or reject comments, commits, code, issues, or other contributions that violate this Code of Conduct, and may temporarily or permanently restrict participation when necessary to protect the community.

Enforcement decisions should be proportionate to the behavior, consistent where practical, and focused on maintaining a safe and productive project environment.
